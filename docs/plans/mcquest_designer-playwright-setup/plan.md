1. Visual observability (screenshots, videos, traces)
2. Pattern consistency (AI can generate new tests)

**Core Patterns:**

```typescript
// Page Object Model (POM) — one class per logical page/component
class EditorPage {
  constructor(private page: Page) {}

  async addQuest() { /* implementation */ }
  async selectQuest(title: string) { /* implementation */ }
  async deleteQuest() { /* implementation */ }
}

// Test structure — descriptive, self-contained
test.describe('Quest Editor - Node Operations', () => {
```

## Requirements

### Performance

**Test Execution Speed:**

- Target: Full suite <3 minutes (local), <5 minutes (CI)
- Individual test: <30 seconds average
- Visual regression tests: <10 seconds per screenshot

**Optimization Strategies:**

1. **Parallel Execution:** Run independent tests concurrently (workers: 4 local, 1 CI)
2. **Smart Waiting:** Use `waitForLoadState('networkidle')` sparingly, prefer specific element visibility
3. **Database Cleanup:** Truncate tables instead of full teardown/rebuild
4. **Fixture Reuse:** Share authenticated sessions across tests where safe
5. **Selective Visual Tests:** Only capture screenshots for critical UI states

**Performance Budget:**

- Authentication tests: 20-40 seconds total
- Editor tests: 40-60 seconds total
- CRUD tests: 30-50 seconds total
- Export tests: 30-50 seconds total
- Visual regression: 30-60 seconds total

Total: ~2.5-4 minutes for full suite

### Security

**Test Isolation:**

- Each test runs against clean database state (prevent data leakage)
- Test user credentials stored in environment variables (never hardcoded)
- Test database completely separate from dev/production
- Clerk test environment isolated from production users

**Secrets Management:**

```bash
# .env.test (gitignored)
DATABASE_URL=postgresql://localhost:5432/mcquest_test
CLERK_SECRET_KEY=sk_test_...
CLERK_PUBLISHABLE_KEY=pk_test_...
TEST_USER_EMAIL=e2e-test@example.com
TEST_USER_PASSWORD=... # Strong password, rotated regularly
```

**CI/CD Secrets:**

- GitHub Actions secrets for test environment variables
- No secrets in playwright.config.ts or test files
- Audit logs for test user actions in Clerk dashboard

**Data Privacy:**

- Test data uses synthetic/fake information (no real user data)
- Test artifacts (screenshots, videos) may contain UI data—store securely
- Automated cleanup of old test artifacts (7 day retention)

**Network Security:**

- Tests run against localhost only (no external dependencies in critical path)
- If testing API integrations, use dedicated test API keys with restricted permissions

```typescript
import { BasePage } from './base-page'

export class EditorPage extends BasePage {
  // Locators
  get addQuestButton() {
    return this.page.getByRole('button', { name: /add new quest/i })
  }

  get questNodes() {
    return this.getByTestId('quest-node')
  }

  get questTitleInput() {
    return this.page.getByLabel(/title/i)
  }

  get questSubtitleInput() {
    return this.page.getByLabel(/subtitle/i)
  }

  get questDescriptionInput() {
    return this.page.getByLabel(/description/i)
  }

  get deleteQuestButton() {
    return this.page.getByRole('button', { name: /delete quest/i })
  }

  get confirmDeleteButton() {
    return this.page.getByRole('button', { name: /^delete$/i })
  }

  // Actions
  async addQuest() {
    await this.addQuestButton.click()
    await this.page.waitForTimeout(500) // Wait for node to render
  }

  async selectQuest(title: string) {
    await this.questNodes.filter({ hasText: title }).first().click()
    await this.page.waitForTimeout(300) // Wait for inspector to open
  }

  async editQuest(data: {
    title?: string
    subtitle?: string
    description?: string
  }) {
    if (data.title) {
      await this.questTitleInput.fill(data.title)
      await this.questTitleInput.blur()
    }
    if (data.subtitle) {
      await this.questSubtitleInput.fill(data.subtitle)
      await this.questSubtitleInput.blur()
    }
    if (data.description) {
      await this.questDescriptionInput.fill(data.description)
      await this.questDescriptionInput.blur()
    }
    await this.page.waitForTimeout(1000) // Wait for autosave
  }

  async deleteQuest() {
    await this.deleteQuestButton.click()
    await this.confirmDeleteButton.click()
    await this.page.waitForTimeout(500) // Wait for deletion
  }

  async dragNode(fromX: number, fromY: number, toX: number, toY: number) {
    const node = this.questNodes.first()
    await node.dragTo(node, {
      sourcePosition: { x: fromX, y: fromY },
      targetPosition: { x: toX, y: toY },
    })
  }
}
```
