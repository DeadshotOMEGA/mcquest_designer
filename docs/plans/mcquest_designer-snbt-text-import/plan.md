### Import Orchestration

**Phased Processing:**
1. **Index Build** (sequential):
   - Parse data.snbt (global config)
   - Index reward_tables/*.snbt
   - Index lang/en_us.snbt
   - Discover chapters/*.snbt files

2. **Entity Parsing** (parallel by chapter):
   - Parse each chapter.snbt file
   - Convert to partial ProjectSnapshot
   - Collect unresolved dependencies

3. **Reference Resolution** (sequential):
   - Build global hexId → UUID index
   - Resolve cross-chapter dependencies
   - Merge language data

4. **Validation** (sequential):
   - Zod schema validation
   - Semantic validation (circular deps, orphans)

5. **Finalization**:
   - Build complete ProjectSnapshot
   - Save to database

**Background Jobs:**
- Service: Inngest (managed, built-in retries)
- Threshold: >100 quests OR >10 chapters
- Progress: Phase-granular events via Inngest step.sendEvent()
- Fallback: Vercel streaming for sync imports

**Error Handling:**
- Strategy: Collect-all-errors (fail-fast optional)
- Severity tiers: fatal/error/warning/info
- Partial import: Optional (default: require error-free)
- Per-file isolation: Chapter parse failure doesn't block others

### Patterns
## Code Patterns from Existing Codebase

**1. FTB SNBT Format Normalization Pattern:**
```typescript
// ftb-adapter.ts handles newline-delimited → comma-separated
const normalized = normalizeFTBQuests(snbtText);
const parsed = parseSNBT(normalized);
```

**2. Bidirectional Conversion Pattern:**
```typescript
// Import flow
const snbtObj = parseSNBT(fileContent);
const langData = parseLangFile(langFileContent);
const snapshot = convertToSnapshot(snbtObj, langData);

// Export flow
const snbtObj = convertFromSnapshot(snapshot);
const snbtText = emitSNBT(snbtObj);
```

**3. Metadata Preservation for Round-Trip:**
```typescript
// Preserve unknown SNBT fields in metadata
metadata: {
  ftbQuestsId: hexId,  // Preserve original ID
  snbtMetadata: unknownFields  // Preserve unknown fields
}
```

**4. Deterministic ID Mapping:**
```typescript
// Sort entities first, then map to hex IDs
const sorted = sortBy(entities, ['order', 'position.y', 'position.x', 'id']);
const idMapper = createIDMapper(sorted, { preserveExisting: true });
```

**5. Validation Before Operations:**
```typescript
const result = validateSnapshot(snapshot, { 
  failFast: false,  // Collect all errors
  warnOnNonBlocking: true 
});
if (result.errors.length > 0) {
  // Handle validation errors
}
```

## FTB Quests SNBT Quirks to Handle

**Hex IDs:** 16-character uppercase (e.g., `4A2123FF92275F64`)
**Newline-delimited:** Fields separated by newlines, not commas
**Type suffixes:** `1.0d` (double), `100L` (long), `5b` (byte)
**Color codes:** `&a` = green, `&r` = reset (Minecraft formatting)
**Escaped ampersands:** `\\&` in strings becomes literal `&`
**Dot-notation lang keys:** `chapter.{id}.title` instead of nested objects
