# 40_docs_style.md — Documentation Rules (Diátaxis)

## 1) Use Diátaxis
Every doc should be one of:
- Explanation
- Reference
- How-to
- Tutorial

Do not mix types.

## 2) Keep docs linkable
- Use stable file names.
- Include a short purpose statement at top.
- Prefer relative links within repo.

## 3) “Docs as memory” guidance
Docs that Claude Code should rely on long-term must:
- avoid ambiguous language
- list invariants explicitly
- include “non-goals”
